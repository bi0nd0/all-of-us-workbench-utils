# Synthetic studies

These configurations use toy concept IDs and generated participants. They cannot define real clinical phenotypes. The alternate example changes the disease, control exclusions, age range, matching variables, method and ratio without editing the library.

Each example also supplies its own `report-content.yaml`, `publication.yaml` and `report-layout.yaml`. The main example uses joint categories and median/quartile summaries; the alternate uses a different binary characteristic and mean/SD summaries. The synthetic notebook generates both checked workbooks. A study can split its required content across sheets without changing the analysis.
